# interaction設計書

## 基本設計

- 英語/日本語両方のエイリアスを用意
- 内部動作は等価

## invite_thread/スレッドに招待

- 招待用ロールを持つ人を全員招待する
- すでに参加している人は対象外
- cacheされているforumはそれぞれrate limiterを持ち、それに従う

## pin/ピン留め \<msg>

- msgで指定したmessageをピン留めする
- スレッド主限定

## question/質問開始

- 特定のフォーラムチャンネルに新たなフォーラムを作成するためのmodalを提供する
- スレッド作成、初期投稿はbotが代理で行う
