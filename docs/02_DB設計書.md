# DB設計

## DB構造

```mermaid
erDiagram
    messages {
        bigint message_id PK
        bigint replied_id
        bigint guild_id
        bigint channel_id
        bigint author_id
        timestamp created_at
    }

    message_posts {
        bigint message_id PK
        timestamp posted_at
        text content
    }

    message_edits {
        bigint edit_id PK
        bigint message_id FK
        timestamp edited_at
        text content_after
        text content_before
        boolean is_partial
    }

    message_deletes {
        bigint message_id PK
        timestamp deleted_at
        text content_before
    }

    message_questions {
        bigint message_id PK
        bigint true_author
    }

    bot_sessions {
        bigint session_id PK
        timestamp started_at
        timestamp ended_at
        text end_reason
    }

    messages ||--|| message_posts : has
    messages ||--o{ message_edits : edited
    messages ||--|| message_deletes : deleted
    messages ||--|| message_questions : supplement
```

- messages.replied_idはnullable
- message_edits.edit_idは自動連番

## DB処理

- insertはバッチ処理
- insertはテーブルごとに異なるtaskとして実行される
- テーブル内での挿入順序は保証される
- update/deleteは使用せず、論理削除を行う
- bot_session tableはdaemon側が操作する
