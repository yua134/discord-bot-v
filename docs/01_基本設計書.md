# 基本設計書

## 動作環境

### 環境に必要なもの

- PostgreSQL

### ディレクトリ構成

#### linux

```txt
project
├─ bot
└─ config.toml
```

#### windows

```txt
project
├─ bot.exe
└─ config.toml
```

### botへの権限

- Guild Member Intent
- Message Content Intent

## 機能

- 自動スレッド招待
- 認証, ロール付与
- 一定期間未認証をkick
- スレ主向けPin
- `/質問開始`
- DM
- messageログ
- ログ
- config差し替え

## 制約

- 1process:1guild

## 言語・メインライブラリ
